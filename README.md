🌠 Mystic Skies – Weather App

A beautifully animated React + Tailwind CSS weather application that allows users to check real-time weather details of any city.
It includes glowing effects, floating sparkles, smooth animations, and a magical dark-royal theme.

🚀 Features

🌆 Search weather by city name

🌦️ Shows weather condition, temperature, and weather description

✨ Magical UI with floating sparkles, glow borders & animated components

⚡ Loading animation while fetching

❌ Error message for invalid city

🎨 Designed fully using Tailwind CSS

📡 Uses OpenWeatherMap API

🛠️ Technologies Used

React.js

Tailwind CSS

Axios for API calls

OpenWeatherMap API

📌 How It Works

User enters a city name in the input box

On clicking Get Report, a request is sent to OpenWeatherMap

App displays:

🌦 Weather main (ex: Clouds, Rain)

🌡 Temperature in °C

📝 Weather description

Beautiful UI animations enhance the experience
